A runnable HTML/CSS/JavaScript recreation of the uploaded screen recording (720 × 1280, 30fps, approx. 21.83 seconds).

## Five effects visible in the recording
1. **Gradient Flow** — animated multi-color text gradient.
2. **Rotate In** — opacity, rotation and scale reveal.
3. **Blur Reveal** — blur and letter-spacing transition.
4. **Neon Flicker** — green neon glow with flickering opacity.
5. **3D Flip** — rotating 3D text using preserve-3d.

## Run
Unzip the project and open `index.html` in a modern browser. No dependencies, installation, or build step required.

## Code extraction fidelity
The recording shows the CSS snippets for all five effects. Their visible values and animation keyframes have been transcribed into the corresponding code panels and implemented in `style.css`. The video is a screen recording, not the original source repository; the page structure, responsive presentation, and copy controls are reconstructed to make the project complete and runnable. Minor punctuation/formatting may be normalized for valid CSS.
